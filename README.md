# গিট গেম বাংলা 🎮

> খেলতে খেলতে গিট শিখুন — **১০ লেভেলে** আসল গিট কমান্ড প্র্যাকটিস করুন, সম্পূর্ণ বাংলায়, সম্পূর্ণ অফলাইনে।

বাংলায় গিট শেখার ভালো ইন্টারঅ্যাক্টিভ রিসোর্স নেই — এই গেম সেই জায়গাটা পূরণ করে। টার্মিনালে কমান্ড লিখুন, গেম সাথে সাথে ফিডব্যাক দেয়, লক্ষ্য পূরণ হলে পরের লেভেল খোলে।

## ✨ Features

- ✅ **১০ লেভেল**: `init` → `add` → `commit` → `status` → `log` → `branch` → `switch` → ফিচার-কমিট → `merge` → `push`
- ✅ **মিনি গিট সিমুলেটর** — ফাইল স্টেজিং, ব্রাঞ্চ, কমিট হিস্ট্রি, মার্জ, ভুল কমান্ডে বাংলায় এরর মেসেজ
- ✅ 💡 প্রতি লেভেলে **হিন্ট** বাটন
- ✅ 🔓 প্রগ্রেস **লোকালস্টোরেজে সেভ** — ব্রাউজার বন্ধ করলেও বাকি থাকে
- ✅ লেভেল ডটে ক্লিক করে আগের লেভেল রিপ্লে
- ✅ টার্মিনাল-স্টাইল ডার্ক ইউআই, মোবাইলেও চলে
- ✅ 100% অফলাইন — একটি মাত্র `index.html`

## 🌍 GitHub Pages-এ ডিপ্লয়

```bash
git init && git add . && git commit -m "Day 7/100: Git Game Bangla - 10-level interactive git learning game"
git branch -M main
git remote add origin https://github.com/iamzahirul/day-07-git-game-bangla.git
git push -u origin main
```

তারপর **Settings → Pages → Deploy from branch → main / (root)** → লাইভ!
